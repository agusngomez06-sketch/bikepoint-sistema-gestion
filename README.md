# BikePoint – Sistema de Gestión de Ventas e Inventario

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un Sistema de Gestión de Ventas e Inventario para BikePoint, una tienda dedicada a la comercialización de bicicletas y sus accesorios.

El objetivo principal es mejorar la organización de las operaciones comerciales, facilitar el registro de ventas y mantener actualizado el inventario de productos.

## Objetivos

- Registrar las ventas realizadas.
- Consultar la disponibilidad de productos.
- Mantener actualizado el stock.
- Organizar la información de clientes y productos.

## Áreas involucradas

- Ventas y Atención al Cliente.
- Administración y Finanzas.
- Depósito e Inventario.
- Sistemas.

## Alcance del sistema

El sistema permitirá gestionar productos, clientes, ventas y cantidades disponibles en el inventario.

## Trabajo Práctico Integrador

Proyecto desarrollado para la asignatura Organización Empresarial de la Universidad Tecnológica Nacional (UTN).
